# آيات مرئية

منصة تحليل بياني ومخططات تفاعلية للقرآن الكريم، تعمل على GitHub Pages.

**الموقع:** https://hamid-kano.github.io/quran-visual/

## الأقسام

- **مجرّة السور**: كل سورة نجم يكبر بعدد آياتها، وتتقارب السور كلما اشتركت في جذورها المميِّزة.
- **شبكة الجذور**: ٤٥١ جذراً من أكثر الجذور وروداً، تربط بينها الآيات التي تجمعها، مع مواضع كل جذر ومشتقاته وتوزيعه على السور.
- **بصمات السور**: شكل لكل سورة من أطوال آياتها وحروف فواصلها.
- **رحلة النزول**: متوسط طول الآية وعدد الآيات بحسب ترتيب النزول.
- **أسماء الأعلام**: شبكة الأعلام التي تجتمع في آية واحدة، مع مواضع كل اسم.
- **المتشابهات اللفظية**: الآيات المتقاربة في ألفاظها مع تظليل مواضع الاختلاف.
- **تحليل الكلمة**: جذر كل كلمة ومدخلها ووصفها الصرفي عند اختيارها في النص.
- **التلاوة**: في صفحة كل سورة وفي المصحف، بأصوات كل قرّاء حفص في EveryAyah (٤٤ قارئًا)، مع تظليل الآية الجارية وتكرارها.
- **المنهج والمصادر**: شرح كيفية حساب كل رقم.

## المبدأ

المنصة تعرض ما يُقاس في النص: العدّ والتوزيع والاقتران. لا تفسّر، ولا تستنبط معنى، ولا تبني على الأرقام دعاوى إعجاز.

## التقنيات

| الطبقة       | الأداة                                                |
| ------------ | ----------------------------------------------------- |
| الواجهة      | React 19 + TypeScript (strict) + Vite                 |
| التنسيق      | Tailwind CSS 4، اتجاه RTL                             |
| المجرّة      | Three.js عبر React Three Fiber                        |
| الشبكة       | Sigma.js + Graphology                                 |
| عقد البيانات | Zod (يُتحقَّق منه عند التوليد وعند التحميل)           |
| الاختبارات   | Vitest                                                |
| النشر        | GitHub Actions → GitHub Pages، مع PWA للعمل دون اتصال |

## البنية

```
sources/          المصادر الخام المعتمدة (مُثبّتة في المستودع)
scripts/          مولّد البيانات، وصفحات الروابط وصور المعاينة بعد البناء (prerender.ts)
public/data/      ملفات JSON الناتجة (تُولَّد في CI، غير مُتتبَّعة)
src/data/         عقد البيانات (schemas) والتحميل
src/features/     المجرّة، الشبكة، المنهج
tests/            فحوص سلامة البيانات
```

الواجهة لا تعرف كيف وُلِّدت البيانات، بل تقرأ ملفات مطابقة لـ `src/data/schemas.ts`. أي مولّد مستقبلي (Python، تعلّم آلي…) يكفيه أن يُخرج الشكل نفسه.

## مشاركة الروابط

لكل صفحة ملف HTML خاص بعنوانها ووصفها وصورة معاينتها (Open Graph)، فرابط سورة الرحمن يظهر في واتساب وتيليغرام باسمها وبصمتها. الصور تُرسم عند البناء من البيانات نفسها، والنص العربي يُشكَّل بـ fontkit ويُحوَّل إلى منحنيات، فلا تعتمد الصور على خطوط جهاز البناء.

## التشغيل محلياً

```bash
pnpm install
pnpm data     # يولّد public/data
pnpm dev
```

قبل كل نشر: `pnpm test` يتحقق من مطابقة النص لملف المجمع حرفاً حرفاً، وعدد السور والآيات والكلمات، وكل رقم يعرضه الموقع على أنه حقيقة. التفاصيل في `VERIFICATION.md`.

## المصادر والتراخيص

- **التلاوات**: [EveryAyah](https://everyayah.com)، تُشغَّل من الموقع مباشرة ولا تُحفظ في المستودع.

- **النص العثماني (حفص)**: ملف مجمع الملك فهد لطباعة المصحف الشريف، نص حفص الإصدار ١٨ (`sources/kfgqpc-hafs-v18.json`)، كما هو دون تعديل. وقد قورن بنص [QuranEnc](https://quranenc.com) (انظر `VERIFICATION.md`).
- **أسماء السور بالحروف اللاتينية**: حزمة [`quran-json`](https://www.npmjs.com/package/quran-json) (CC BY-SA 4.0).
- **بيانات السور وترتيب النزول**: مشروع [Tanzil](https://tanzil.net) عبر حزمة [`quran-meta`](https://www.npmjs.com/package/quran-meta) (MIT).
- **الجذور والمداخل**: [Quranic Arabic Corpus](https://corpus.quran.com) v0.4، بنسخة [mustafa0x/quran-morphology](https://github.com/mustafa0x/quran-morphology) المنقّحة (GNU GPL). الملف في `sources/` كما هو دون تعديل.
- **الخطوط**، لكلٍّ منها دور واحد:
  - **خط المصحف من مجمع الملك فهد** (KFGQPC HAFS Uthmanic Script، الإصدار ١٨): نص القرآن الكريم وحده، لأنه الخط الذي وُضع ترميز النص له. يُوزَّع دون تعديل وفق ترخيصه (`public/fonts/KFGQPC-FONT-LICENSE.txt`)، وليس ترخيصه SIL OFL.
  - **Amiri** (SIL OFL): العناوين والقراءة الطويلة.
  - **IBM Plex Sans Arabic** (SIL OFL): الواجهة والأرقام والبيانات.
